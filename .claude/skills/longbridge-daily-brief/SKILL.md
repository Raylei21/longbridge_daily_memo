# 长桥日报 (longbridge-daily-brief)

## 概述

你是一个专业的金融日报生成器 (Daily Brief)。你将生成一份结构化的长桥日报，包含以下六个部分：

1. **仓位与操作分析** — 持仓组合分析、盈亏、风险评估
2. **交易复盘** — 对当日交易的价格、仓位、时机做专业评价（仅当日有交易时显示）
3. **持仓公司社区情报** — 各持仓标的的新闻动态、社区讨论，以及**交易员 vs 中长期投资者**双视角操作策略建议
4. **社区热力板块扫描** — 当前社区讨论热度最高的板块
5. **自选股催化机会扫描** — 从全部自选股中筛选催化潜力最大的3只，并给出**交易员 vs 中长期投资者**双视角操作策略建议
6. **宏观流动性监测** — CPI/PPI最新数据、国债拍卖与收益率、交易员视角的宏观解读与操作建议

> 注：本技能替代原 `longbridge-memo`，在原有三部分基础上增加了自选股催化机会扫描，并自动生成美化 HTML + PDF + 归档页面。后续所有日报请求请使用本技能。

## 关键交付物

| 文件 | 路径 | 说明 |
|------|------|------|
| 当日 Markdown | `longbridge_memo_{YYYYMMDD}.md` | 原始报告 |
| 当日美化 HTML | `longbridge_memo_{YYYYMMDD}.html` | 单日报表，适合浏览器阅读 |
| 当日 PDF | `longbridge_memo_{YYYYMMDD}.pdf` | 打印/分享 |
| **归档 HTML** | `longbridge_daily_brief_archive.html` | **所有日报的 tab 切换页面，点这个链接翻阅过往日报** |

> 归档文件自动维护：每次生成新日报时，`generate_pdf.py` 会自动调用 `build_archive.py` 重建归档。

## 数据时间范围规则

日报的数据采集按以下时间窗口策略执行（假设今天是 `T日`，日报日期为 `T-1日`）：

| 数据类型 | 时间窗口 | 说明 |
|----------|----------|------|
| 持仓+盈亏 | 当前快照 | 实时数据，无需过滤 |
| 📝 交易记录 | **T-1日全天** | 北京时间 `T-1日 00:00` ~ `T-1日 24:00` |
| 📰 新闻 | **严格 24h** | 北京时间 `T-1日 05:00` ~ `T日 05:00` |
| 💬 话题 | **宽松 48h** | 北京时间 `T-2日 05:00` ~ `T日 05:00` |
| 📊 报价/资金流向 | 当前交易数据 | 盘前/盘中快照 |
| 📅 财报日历 | 未来数据 | 不涉及回溯 |
| 📊 宏观数据 | 宽松 7天 | 搜索 T-7日 ~ T日 内的CPI/PPI/国债拍卖/非农新闻 |

### 如何计算时间窗口

当前时间 `T` 是用户请求日报的时间。日报日期是 `T-1日`。

举例：用户 5/12 11:11 请求 5/11 日报
- **新闻窗口**: 5/11 05:00 CST ~ 5/12 05:00 CST = UTC 5/10 21:00 ~ 5/11 21:00
- **话题窗口**: 5/10 05:00 CST ~ 5/12 05:00 CST = UTC 5/09 21:00 ~ 5/11 21:00

### 如何过滤

API 返回的 JSON 中每条记录都有 `time` 字段（ISO 8601 格式，如 `2026-05-11T13:30:29Z`），客户端按时间戳过滤：

- 使用 `longbridge news search <KEYWORD> --count 20 --format json` 获取20条，按 `time` 字段筛选在新闻窗口内的条目
- 使用 `longbridge topic search <KEYWORD> --count 20 --format json` 获取20条，按 `time` 字段筛选在话题窗口内的条目
- 不需要使用 `longbridge news <SYMBOL>`（该API不带时间戳）

## 工作流程

### 第一阶段：获取基础数据

执行以下命令收集基础数据：

1. `longbridge market-temp US --format json` — 获取美股市场温度
2. `longbridge portfolio --format json` — 获取持仓组合
3. `longbridge order --history --start <T-1日> --end <T日> --format json` — 获取T-1日交易记录（用于交易复盘模块）
4. `longbridge watchlist --format json` — 获取全部自选股列表（267只）
5. `longbridge finance-calendar report --filter watchlist --market US --start <今天> --end <30天后> --format json` — 自选股未来30天财报日历
6. `longbridge finance-calendar macrodata --market US --star 3 --start <今天> --end <14天后> --format json` — 未来2周重要宏观数据

#### 宏观流动性数据（新增）

以下命令在**第一阶段末尾**统一执行，供第六阶段使用：

```bash
# CPI/PPI/通胀相关新闻（宽松7天窗口，搜索后按 published_at 过滤）
longbridge news search "美国CPI" --count 10 --format json
longbridge news search "美国PPI" --count 10 --format json
longbridge news search "通胀 inflation CPI" --count 10 --format json

# 国债拍卖数据
longbridge news search "国债竞拍 Treasury auction" --count 10 --format json
longbridge news search "国债收益率 Treasury yield" --count 10 --format json
longbridge news search "初请失业金 jobless claims" --count 10 --format json
longbridge news search "非农 NFP employment" --count 10 --format json

# 通过 news detail 获取关键条目的详细内容
# 筛选出有数据的条目后对每一条执行:
# longbridge news detail <news_id> --format json
```

### 第二阶段：交易复盘（新增模块）

> 此模块**仅当 T-1 日有交易记录时显示**。如果没有交易，跳过此部分，直接生成第三部分。

#### 获取附加数据

对有交易的标的，获取日内行情以评价执行价格质量：

- `longbridge quote <SYMBOL> --format json` — 获取当日 high/low/open/close
- （可选）`longbridge intraday <SYMBOL> --format json` — 获取日内分时数据

#### 评价框架

对**每笔交易**（每个 order 条目），从以下三个维度评价：

| 维度 | 评分标准 |
|:---|---|
| 🎯 **执行价格** | 对照当日价格区间：顶部1/3 = 5分，中部 = 3分，底部1/3 = 1分 |
| 📐 **仓位管理** | 占标的持仓比例：小仓(<20%) = 安全，中仓(20-50%) = 中性，大仓(>50%) = 激进 |
| ⏱ **时机选择** | 结合当日新闻/板块走势/市场温度判断 |

#### 专业视角分析模板

对每笔交易，基于以下框架输出评价：

1. **做得好的地方** — 肯定合理的决策逻辑
2. **可以改进的地方** — 指出价格/仓位/时机上的不足
3. **专业交易员会怎么做** — 对比机构/职业trader的典型操作
4. **下次建议** — 具体的、可操作的改进建议

### 第三阶段：持仓公司社区情报
- 对每个持仓标的执行新闻搜索（必须用 search 子命令，因为 `news SYMBOL` 不带时间戳）：
  - `longbridge news search <SYMBOL> --count 20 --format json`
  - 从结果中筛选 `time` 字段在**新闻窗口**内的条目，取前5条
- 对每个持仓标的执行话题搜索：
  - `longbridge topic search <SYMBOL> --count 20 --format json`
  - 从结果中筛选 `time` 字段在**话题窗口**内的条目，取前5条
- 如果筛选后某标的新闻或话题不足3条，可适当放宽到标题含符号名的所有结果（避免该标的显示空白）

### 第四阶段：社区热力板块扫描
- 新闻维度（高覆盖率，可直接用作板块热度佐证）：
  - `longbridge news search AI --count 20 --format json`
  - `longbridge news search 半导体 --count 20 --format json`
  - `longbridge news search 芯片 --count 20 --format json`
  - 筛选 `time` 在**新闻窗口**内的条目
- 话题维度（辅助判断社区情绪，48h窗口）：
  - `longbridge topic search AI --count 20 --format json`
  - `longbridge topic search 半导体 --count 20 --format json`
  - `longbridge topic search 芯片 --count 20 --format json`
  - `longbridge topic search <当日热门关键词> --count 20 --format json`
  - 筛选 `time` 在**话题窗口**内的条目
- 综合新闻覆盖量和话题互动量，选出热度最高的2-3个板块进行分析
- 如果话题窗口内结果不足，可用新闻结果为主要依据

### 第五阶段：自选股催化机会扫描

这是增强版的核心新增部分。请按以下步骤执行：

#### 步骤1：获取自选股报价 — 筛选异动标的

将全部自选股符号分批查询报价（每批最多50只）：

> `longbridge quote <SYMBOL1> <SYMBOL2> ... --format json`

从中筛选出以下异动标的：
- 当日涨跌幅 > ±3% 的标的
- 成交量显著放大的标的
- 盘中价格有异常波动的标的

#### 步骤2：排除持仓标的

排除已在持仓中的标的（因为持仓已在第一部分覆盖），保留纯自选股。

#### 步骤3：交叉验证催化信号

对步骤2筛选出的候选标的，按以下优先级做交叉验证：

**优先检查（最高权重）：**
- 是否在未来30天内有财报发布（从步骤1的财报日历数据中匹配）
- 财报是否符合市场预期超预期概率高

**次优先检查：**
- 使用 `longbridge news search <SYMBOL> --count 20 --format json` 检查近期是否有重大新闻：
  - 筛选 `time` 在**新闻窗口**内的条目
  - 重点检查：分析师评级上调/下调、新产品/合同获批、并购/重组消息、回购/分红计划、管理层变动

**辅助检查（如有余力）：**
- 使用 `longbridge capital <SYMBOL> --format json` 检查是否有异常资金流入
- 使用 `longbridge intraday <SYMBOL> --format json` 检查日内走势

#### 步骤4：排名与输出

综合评估以下维度，对候选标的排名打分（每项1-5分）：

| 维度 | 权重 | 判断标准 |
|------|------|---------|
| 近期催化剂事件 | 30% | 是否有明确的近期催化事件（财报、FDA、合同等） |
| 股价异动幅度 | 20% | 近期是否有突破性走势或放量上涨 |
| 资金流入信号 | 20% | 是否有明显的资金净流入 |
| 社区/新闻热度 | 15% | 社区讨论是否活跃、新闻面是否正面 |
| 事件确定性 | 15% | 催化剂事件发生的概率和时间的确定性 |

选出总分最高的 **3只标的**。

### 第六阶段：宏观流动性监测

> 此模块**始终显示**，位于自选股催化扫描之后、财报雷达之前。
> 数据来源：以 `news search` 为主（覆盖更全），`finance-calendar macrodata` 为辅。

#### 数据筛选与提炼

对第一阶段获取的宏观新闻数据，按以下规则处理：

1. **CPI/PPI/通胀数据**
   - 从 `news search` 结果中筛选标题包含 `CPI`、`PPI`、`通胀`、`inflation` 的条目
   - 按 `published_at` 过滤在宽松7天窗口内的条目
   - 取热度最高的 2-3 条，用 `news detail` 获取全文
   - 提取关键数据点：CPI年率/月率、核心CPI、PPI、前值、预期、实际值

2. **国债拍卖数据**
   - 从 `news search "国债竞拍"` 结果中筛选各期限国债条目
   - 提取：得标利率(winning yield)、投标倍数(bid-to-cover)、前值
   - 区分短端（4周/8周）和长端（10年/30年）数据
   - 关注标志性事件（如30Y破5%、投标倍数显著变化等）

3. **就业数据**
   - 从 `news search` 结果中筛选初请失业金和非农相关条目
   - 提取：申请人数、前值、市场反应

4. **finance-calendar macrodata 补充**
   - 查询结果如有未来2周的待发布数据，加入"待发布"表格
   - 如查询结果为空，不报错，跳过该子模块

#### 分析框架

从**交易员视角**对宏观数据做三层递进分析：

**第一层：核心判断**
- 定性当前宏观环境（滞胀/复苏/衰退/过热）
- 列出5维度全景表：经济增长、通胀路径、利率预期、美元走势、波动率

**第二层：对持仓的穿透影响**
- 逐一分析每只持仓的宏观敏感度（⭐⭐⭐/⭐⭐/⭐）
- 说明具体的传导路径：为什么利好/利空，量化影响程度
- 结合持仓当前仓位给出风险评估

**第三层：可执行操作建议**
- 基于宏观判断给出具体的仓位调整建议（标的、方向、比例）
- 涉及期权策略时给出具体行权价和期限
- 分短期（1-4周）和中期（1-3个月）两个维度
- 标记近期关键事件的时间窗口（如CPI发布日、FOMC会议日）

### 第七阶段：日报输出格式

整份日报按以下结构和格式写入 markdown 文件：

**输出文件路径**: `$PROJECT_DIR/longbridge_memo_{YYYYMMDD}.md`（`$PROJECT_DIR` 为项目根目录，即脚本所在目录）

**重要格式规则**（必须遵守，否则HTML渲染会出错）：

1. **表格前必须有空行** — 任何表格（`| ... |`）之前必须有一个空行，包括在 `**粗体标题**` 后面。错误示例：
   ```
   **关键催化**
   | 事件 | 日期 |    ← 错误！没有空行
   ```
   正确示例：
   ```
   **关键催化**

   | 事件 | 日期 |    ← 正确！有空行
   ```

2. **使用原生 emoji** — 不要替换或移除任何 emoji 符号（🏆🥈🥉🟢🟡✅⚠️👥📰💬🔥⭐⏱），浏览器原生渲染良好

3. **特殊字符保留原始 Unicode** — 使用 `━━`（U+2501）、`▶`（U+25B6）、`→`（U+2192）、`▲`（U+25B2）、`▼`（U+25BC）、`█░`（U+2588/U+2591）等原始字符，不要替换为 ASCII 替代

4. **h1/h2 层级** — 标题 `#` 为日报主标题，`##` 为四大章节，`###` 为子章节

5. **代码块内的进度条** — 使用 ``` 代码块包裹，格式如下：
   ```markdown
   ```
   热度: ██████████ 100%  |  20+ 话题  |  3,000+ 互动量
   ```
   ```
   催化评分:  ██████████ 4.7 / 5.0
   ```
   盘前状态:  $238.02  ▲ +8.64%  |  成交量 1,200,124 股
   ```

## 注意事项

1. 每批查询quote时不超过50只符号，用空格分隔
2. 如果 `finance-calendar report --filter watchlist` 返回空或报错，改用 `finance-calendar report --symbol <symbol1> --symbol <symbol2> ...` 分批查询
3. 催化事件分析要具体，避免泛泛而谈（如不要只说"即将发布财报"，要说明市场预期、过往业绩趋势）
4. 每个标的的催化评分需要有明确的打分依据，在分析中体现
5. 如果扫描过程中发现特别强烈的催化信号（如突发重大新闻），可以在"其他值得关注的标的"中补充说明
6. **严格遵循时间窗口规则**：新闻严格按24h窗口过滤，话题按48h窗口过滤。时间窗口的计算逻辑见「数据时间范围规则」章节。如果某标的过滤后数据不足3条，可放宽至不过滤但需在报告中标注「该标的时间窗口内数据较少」
7. **宏观流动性模块数据来源优先级**：以 `news search` 为主（覆盖更全），`finance-calendar macrodata` 为辅。如果 `macrodata` 查询返回空，不要报错，跳过「未来2周待发布」子模块即可
8. **国债拍卖新闻的标题解析**：国债拍卖新闻标题中含有结构化数据（如「得标利率 3.605%」「投标倍数 2.66」），直接从标题中提取数值，结合 `news detail` 的 description 字段验证。4周和8周国债新闻各自独立，需要分别提取
